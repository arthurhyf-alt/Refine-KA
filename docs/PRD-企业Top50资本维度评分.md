# PRD：Refine-KA 企业 Top50 资本维度评分功能

> 版本：v1.0 ｜ 日期：2026-09-01 ｜ 分支：`feature/financing-ranking`
> 状态：核心逻辑已实现并验证（8131 家公司 / 37 行业 / 98% 融资分覆盖）

---

## 1. 背景与问题

**现状**：Refine-KA 产业筛查器在每个「细分地区 × NS 行业（分组/评级）」视图下输出 Top 50 公司，但排序仅依据 A 股市值——市值只反映公司规模，不反映**资本活跃度与融资能力**。

**用户场景**：产业研究 / BD 人员按地区（全国/上海/浙江/福建/江西）和行业筛出目标赛道后，需要快速判断「哪些公司正在被资本追逐」——两融资金是否活跃、主力资金是否流入、未上市公司走到了哪一轮。

**问题定义**：Top50 排序缺少资本/融资维度的量化输入；未上市公司只有「专精特新/多轮融资」标签，没有 A/B/C/D 轮的结构化信息。

## 2. 核心功能定义

> **一句话**：在每个 细分地区 × 行业 视图下，输出 50 家公司的综合排序：
> **综合分 = 市值排名分 × 65% + 资本/融资分 × 35%**

| 要素 | 说明 |
|---|---|
| 输入 | 行业底池（A 股公开数据）+ 未上市补充池（政府名单/公开报道） |
| 核心计算 | 资本维度打分（上市公司三信号 / 未上市公司轮次评分） |
| 输出 | 每行业×地区 Top50 公司表（总分 + 资本分 + 覆盖率 + 可溯源证据链接） |
| 更新机制 | 「抓取最新公开数据」按钮触发全量重采（约 8 分钟；缓存命中约 20 秒） |

## 3. 评分体系（已实现）

### 3.1 上市公司：三信号加权（0-100）

| 信号 | 权重 | 数据源（公开、免 key） | 映射 |
|---|---|---|---|
| 两融参与度 | 35% | 东方财富·个股融资余额 ÷ 流通市值（新浪） | 0%→45 分，≥6%→100 分 |
| 主力资金净流入 | 35% | 新浪·当日 r0_net ÷ 流通市值 | +1%→90 分，−1%→30 分 |
| 大宗交易 | 30% | 东方财富·当日成交额 + 折价率 | 0.5% 封顶 90 分；折价每 1% 扣 1 分 |

- 子项缺失 → 按剩余子项归一化；全部缺失 → 本维度不计分（覆盖率下降，不误导）
- 置信度：3 信号 0.75 / 2 信号 0.68 / 1 信号 0.58

### 3.2 未上市公司：融资轮次评分（0-100）

`轮次深度 45% + 累计金额 30% + 最近融资时间 15% + 投资方质量 10%`

- 轮次深度：天使 12 → A 22 → B 32 → C 38 → D 44 → E/基石 46-48 → IPO 50
- 投资方质量：识别国家队/顶级 VC 关键词（腾讯、高瓴、IDG、国投、中金等）
- 示例（已核实）：壁仞 95 分（10 轮/87 亿/已港股 IPO）、燧原 90.4（8 轮/70 亿/IPO 受理）、海辰储能 75.2（天使-A-B 20 亿-C 45 亿）

### 3.3 兜底与降级（保证 Top50 始终有 50 行）

| 场景 | 处理 |
|---|---|
| 某地区某行业候选 < 50 | 从全国候选按市值递补，证据标注「跨地区补足」 |
| 上市公司融资信号缺失 | 按中性 55 分参与排序，不拉低其他维度 |
| 未上市公司无轮次明细 | 降级为阶段标签评分，证据明示「轮次明细未采集」 |
| 公司已上市（如宇树 688836） | 自动移入 A 股底池，走上市公司三信号逻辑 |

## 4. 数据源分层与 MCP 沉淀（迁移给不同用户的关键）

| 层级 | 数据能力 | 依赖 | 迁移要求 |
|---|---|---|---|
| **L1 公开 API**（当前实现） | 两融/主力资金/大宗/全市场市值 | 无 key、纯 Python 标准库 | **开箱即用**，随代码分发即可 |
| **L2 MCP Connector** | 未上市公司全量融资历史（A/B/C/D 轮/投资方/估值） | 企查查 / 天眼查 connector | 用户在 WorkBuddy 连接后可用；**融资数据获取需沉淀为独立 MCP skill**，与本地代码解耦 |
| **L3 付费数据库** | 机构级口径（清科 PEDATA / 投中 CVSource） | 付费账号 | 仅专业客户按需接入 |

**MCP 沉淀原则**：`financing.py` 的三信号采集与评分逻辑保持「无外部依赖、可独立调用」的模块边界，未来封装为 MCP tool（输入：股票代码列表/公司名 → 输出：结构化资本分 + 证据），供不同用户的 agent 复用，而不绑定在本应用内。

## 6. 边界与已知限制

1. **8 个行业凑不满 50**（aerospace 15 / shipbuilding 10 / paper 44 / oil-gas 49 等）——A 股细分行业实际公司数不足，跨地区兜底后仍有限；属市场客观事实，UI 已如实展示。
2. **补充池 43 家中仅 5 家有完整轮次明细**——其余为省级专精特新中小企业，公开渠道无融资报道；需 L2（企查查 MCP）补全。
3. 数据时效：两融/资金流为当日快照，大宗为最新交易日；缓存 6 小时内不重采。

## 8. 验收口径

- 每个行业×地区点开，Top50 表始终 50 行（或接近，受市场实际限制）
- 每条资本分都附可点击来源链接（东财/新浪/公开报道）
- 点「抓取最新公开数据」后分数随市场变化（非固定值）
- 换一台机器解压/clone 后无需安装额外依赖即可运行（L1 能力）
